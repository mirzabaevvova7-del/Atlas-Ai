# ATLAS AI — Android

Биринчи MVP версияси: экрандаги микрофон тугмаси орқали ўзбекча/русча овозни таниш, TTS жавоблари ва асосий Android амаллари.

## Қўллаб-қувватланадиган буйруқлар
- Telegram ва YouTube очиш
- Браузер очиш
- SMS ёзиш ойнаси
- Қўнғироқ ойнаси
- Будильниклар рўйхати
- Медиа овозини кўтариш/пасайтириш

## Чекловлар
- Ҳозирча wake-word ("ATLAS") доимий фон тинглаши йўқ.
- Қўнғироқни ўзи бошламайди; рақам териш ойнасини очади.
- AI чат/API интеграцияси бу версияга киритилмаган.
- Овоз таниш ва TTS сифати Android қурилмадаги тил пакетларига боғлиқ.
